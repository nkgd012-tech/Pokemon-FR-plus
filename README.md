# Pokemon-FR-plus
* It’s simply the original FireRed ROM, but with upgraded graphics to make it more visually pleasing for the user.

#what’s in this patch?

+graphics in the DS style

+The HP bar and text box have been updated to resemble those in HGSS.

+New intro, main menu has been changed

+The Pokémon stat-viewing screen is designed in the style of BW.

+The Pokémon party screen has been adjusted to resemble the one in HGSS.

+D/P/PT-style font and New start menu.

+custom battlegrounds and new status-type icon.

#known issue:

When loading a save file, the tiles become jumbled, which is visually confusing.

But don't worry; you can fix them yourself by entering a house and then coming back out—everything will return to how it was.
